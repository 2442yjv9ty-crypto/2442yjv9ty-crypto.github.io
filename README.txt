IDEAS IN PROGRESS — WEBSITE

1. Unzip the folder.
2. Open index.html in a browser to preview.
3. Upload index.html, style.css, and the entire assets folder to the ROOT of your GitHub Pages repository (the same folder level).
4. Commit changes. Refresh your GitHub Pages website after a few minutes.

PHOTO NOTE: The two portrait assets are the uploaded photos selected for this starter. If they are not the exact photos you intended, replace assets/portrait-main.jpg and assets/portrait-id.jpg with the correct images using the SAME file names.

All text and colors can be edited in index.html and style.css. Burgundy color: --red:#6f1729 in style.css.
